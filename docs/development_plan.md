# Development Plan

목표일은 2026년 8월 11일이며, 일정은 Pilot 문서 확보와 통합 결과에 따라 팀이 조정합니다.

| 순서 | 단계 | 완료 기준 |
| --- | --- | --- |
| 1 | 환경 구축 | 세 담당자가 `uv sync`와 기본 검사를 실행 |
| 2 | Pilot XML 선정 | 비식별 처리 기준과 담당 문서 유형 확정 |
| 3 | 공통 Schema 확정 | 샘플 입출력과 필수 필드 합의 |
| 4 | 개별 기능 개발 | 담당 Slice의 단위 테스트 통과 |
| 5 | 1차 통합 | 질문에서 근거 후보까지 계약 기반 연결 |
| 6 | 오류 수정 | 단위·계층·정정 연결 주요 오류 해소 |
| 7 | MVP 완료 | 포함 범위 시나리오와 근거 표시 검증 |
